# 🚀 Установка HubSpot MCP Сервера за 1 Клик (Windows / macOS / Linux)

Этот сервер позволяет вашим менеджерам по продажам (сейлзам) подключаться к **HubSpot** прямо через **Cursor** или **Claude Desktop** с помощью искусственного интеллекта. Они смогут искать контакты, смотреть детали, создавать и обновлять сделки простым человеческим языком на русском!

Мы сделали этот продукт **абсолютно кроссплатформенным** и полностью автоматическим. Сейлзам больше **не нужно писать сложные команды, вручную настраивать JSON-файлы или искать скрытые папки**. Скрипт сделает всё за них!

---

## 🛠️ Предварительная настройка (Делает Админ/Разработчик ОДИН раз)

Перед тем как отправить папку сейлзам:
1. В аккаунте HubSpot перейдите в **Settings** (Шестеренка) > **Integrations** > **Developer Apps** (или **MCP Auth Apps**).
2. Нажмите **Create MCP auth app** (или обычное OAuth App).
3. Укажите:
   * **App Name:** `Cursor HubSpot Integration`
   * **Redirect URL:** `http://localhost:6274/oauth/callback/debug`
4. Сохраните приложение. Скопируйте **Client ID** и **Client Secret**.
5. Скопируйте файл `.env.example` в этой папке, переименуйте его в `.env` и вставьте туда скопированные ключи:
   ```env
   HUBSPOT_CLIENT_ID=d15a5972-d9d4-42ee-8943-9058b2a02042
   HUBSPOT_CLIENT_SECRET=eed451de-76dd-4667-a747-cda00064995e
   ```
6. Убедитесь, что папка `build` скомпилирована (вы запустили `npm run build` перед отправкой).
7. Заархивируйте папку в ZIP-архив (можно без папки `node_modules` — скрипты установки сами всё скачают!) и отправьте сейлзам.

## 💻 Инструкция для менеджеров по продажам (Всего 2 шага!)

### Шаг 1. Распакуйте архив
Скачайте архив с программой и распакуйте его в любую удобную папку на компьютере (например, `C:\hubspot-mcp-server\` на Windows или в домашнюю папку на Mac).

### Шаг 2. Запустите авто-настройку

#### 🖥️ На Windows:
1. Найдите файл **`setup.bat`** внутри папки и запустите его двойным щелчком мыши.
2. Скрипт сам проверит Node.js (если его нет — установит в фоновом режиме), **автоматически найдет и настроит Claude Desktop и Cursor**, после чего откроет браузер.
3. В открывшемся браузере выберите ваш рабочий портал HubSpot и нажмите **«Подключить приложение»** (Authorize).
4. Готово!

#### 🍎 На macOS (Mac):
1. Откройте Терминал и перейдите в папку с проектом.
2. Запустите команду:
   ```bash
   bash setup.sh
   ```
3. Скрипт проверит наличие Node.js (если его нет — установит через Homebrew), **автоматически настроит Claude Desktop и Cursor** и откроет браузер.
4. В браузере выберите рабочий портал HubSpot и нажмите **«Подключить приложение»** (Authorize).
5. Готово!

## 🤖 Как начать работу?

После успешного выполнения скрипта **перезапустите** приложения Claude Desktop или Cursor.

* **В Claude Desktop:** В чате появится значок розетки/вилки (MCP), нажав на который вы увидите все наши инструменты.
* **В Cursor:** Сервер подключится автоматически на глобальном уровне! Вы увидите его в настройках **Features > MCP** под именем `HubSpot`.

### Примеры запросов:
Просто пишите ИИ человеческим языком:
* *«Найди сделку по компании Ромашка»*
* *«Выведи мне последние 3 контакта с их именами и email»*
* *«Создай сделку Тестовая на сумму 15000 рублей»*
* *«Сделай сделку с ID 12345 успешной (closedwon)»*
